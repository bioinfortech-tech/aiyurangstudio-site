In-house Tools

영상을 만들고,
만드는 도구까지 만듭니다.

유랑스튜디오는 영상 스튜디오이자, 작업에 쓰는 소프트웨어를 직접 개발하는 팀입니다. 현장에서 필요했던 것을 필요한 모양으로 만들어 쓰고, 계속 고쳐 나갑니다.

오토에디터 자체 개발 자동 편집 엔진

컷 편집, 자막, 음악 리듬 맞춤을 자동으로 처리하는 자체 편집 엔진입니다. 어디서 자르고 무엇을 남길지의 판단은 사람 감독 아래에서 이루어집니다.

리뷰 · 피드백 시스템 클라이언트 검토 도구

영상 위 원하는 타임코드에 바로 코멘트를 달고 그림으로 표시할 수 있습니다. 수정본은 버전별로 정리되어 어떤 의견이 어떻게 반영됐는지 한눈에 남습니다. 화면을 눌러 직접 표시해 보세요.

멀티 컴퓨터 AI 제작 파이프라인 자체 렌더 · 생성 파이프라인

여러 대의 GPU 워크스테이션이 서로 작업을 나눠 맡고 주고받는 자체 렌더·생성 파이프라인입니다. 한 대의 한계에 작품이 묶이지 않도록 구성했습니다.

자동 배포 · 업로드 자체 배포 도구

완성된 영상을 채널별 일정에 맞춰 올려 주는 자체 도구입니다. 올리는 일은 도구가 맡고, 무엇을 언제 보여줄지는 사람이 정합니다.

도구는 연출을 대신하지 않습니다. 반복되는 일을 맡고, 감독은 장면에 더 오래 머뭅니다.
