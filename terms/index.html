이용약관

dubu-uploader (유랑스튜디오) · 시행일 2026-11-16

1. 서비스

dubu-uploader는 유랑스튜디오(대표 유홍양)가 내부에서만 쓰는 도구입니다. 스튜디오가 소유한 유튜브 채널(@dddubbbu)에 스튜디오가 직접 만든 영상을 올리고, 공개 일정을 정하고, 채널 통계를 확인합니다. 외부 사용자에게 제공하거나 판매하지 않습니다.

2. YouTube 서비스 약관

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 사용하는 사람은 YouTube 서비스 약관을 따라야 하며, 이에 동의한 것으로 봅니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

3. 사용 범위

  • 스튜디오가 권리를 가진 영상만 올립니다.
  • 다른 채널이나 다른 사람의 데이터에 접근하지 않습니다.
  • YouTube 콘텐츠를 내려받거나 다시 배포하지 않습니다.

4. 개인정보

개인정보처리방침을 따릅니다.
