dubu-uploader (유랑스튜디오) · 시행일 2026-11-16

1. 이 앱이 하는 일

dubu-uploader는 유랑스튜디오가 직접 운영하는 내부 도구입니다. 스튜디오가 관리하는 유튜브 채널(@dddubbbu)에 직접 만든 영상을 올리고, 예약 공개를 설정하고, 그 채널의 조회수·시청 시간 같은 통계를 읽어 오는 데만 씁니다. 일반 사용자에게 제공되는 서비스가 아닙니다.

2. YouTube API 서비스 사용

dubu-uploader는 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 개인정보 처리 방식은 Google 개인정보처리방침을 참고하세요.

3. 사용하는 Google 데이터

  • youtube.upload: 채널에 영상 업로드
  • youtube.readonly: 채널과 업로드한 영상 정보 확인
  • yt-analytics.readonly: 채널 통계 보고서 확인

다른 사람의 계정이나 개인정보는 수집하지 않습니다.

4. 보관과 공유

로그인 토큰은 스튜디오 내부 서버의 접근 제한 폴더에만 저장합니다. Google 사용자 데이터를 판매하거나 광고에 쓰거나 제3자와 공유하지 않습니다. 통계는 스튜디오 내부 제작 기획에만 씁니다.

Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회와 삭제

채널 소유자는 언제든 Google 계정 권한 설정에서 이 앱의 접근을 해제할 수 있습니다. 해제하거나 요청하면 저장된 토큰을 삭제합니다. API로 받은 채널 통계는 내부 보고서에만 쓰고, 30일 안에 갱신하거나 삭제합니다. 권한을 해제하면 7일 안에 저장된 모든 API 데이터를 삭제합니다. 삭제 요청은 아래 이메일로 보내 주세요.

YURANGSTUDIO 홈페이지(www.yurangstudio.com)의 상담 채팅은 상담에 답하기 위해 대화 내용과 방문자가 직접 남긴 이름·연락처(이메일 또는 전화번호)를 저장하고, 담당자에게 텔레그램으로 전달합니다. 상담 기록은 90일 뒤 삭제하며, 상담 외의 목적으로 쓰거나 제3자에게 제공하지 않습니다.
