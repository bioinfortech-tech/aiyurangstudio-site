무엇을 하나요

유랑스튜디오가 직접 만든 영상을 스튜디오 소유 유튜브 채널에 올리고, 공개 일정을 정하고, 채널 통계를 확인하는 내부 도구입니다. 외부 사용자에게 제공하지 않습니다. YouTube API 서비스를 사용합니다.

An internal tool that uploads Yurangstudio's own videos to the studio's own YouTube channels, schedules their publication and reads channel analytics. Not offered to the public. Uses YouTube API Services.
